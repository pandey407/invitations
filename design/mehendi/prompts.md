Built from Aarusha's Pinterest board **Final props** (33 pins): bangle cards and a bangle bar,
photo-booth speech bubbles and arrows, Bollywood/truck-art posters ("Abhi bhi time hai bhaag ja",
"Khao piyo vibe karo", "Aao chill karein"), direction signs, caricature stickers with filmy dialogues,
hair-clip favour cards, petal cones with a monogram, embroidery-hoop "Team Bride" placards, a retro
candy station, and table cards with childhood photos.

**Workflow**
1. Run **Prompt 0** with the couple photo attached → save the avatar sheet.
2. For every other prompt, attach the avatar sheet + `hero.jpeg` (our mehendi card) and paste the
   **Style lock** block first, then the prop prompt.
3. If lettering comes out garbled, add "leave all text areas blank" and set the type in Canva.

## 5a. Stroked monogram — English + Nepali on one grid

v1 (bubbly, mehendi-patterned) was too busy. v2 follows the petal cones on the mood board: the
"D&M" cone (thin stacked serif initials with a fine olive sprig) and the "Tanvi & Sahil" cones (a
light, wavy, handwritten monoline signature). Attach those two pins if you can.

Initials: Aarusha → "A" / "आ", Ashlesh → "A" / "अ". (In Nepali they differ: आ and अ.)

```
Design a monogram sheet for a couple, laid out as a clean 3 x 2 grid of six square tiles on a plain
cream (#F6EEDF) background, a thin light-grey line between tiles, each monogram centred with lots of
empty space around it. Style reference: the attached petal cones: thin, elegant, STROKED lettering,
like a fine pen or a single gold foil line, not filled, not bold, no patterns inside the letters.

TOP ROW (English): "A & A".
BOTTOM ROW (Nepali, Devanagari): "आ & अ" (आ for Aarusha, अ for Ashlesh). Spell the Devanagari
exactly: आ, then &, then अ. Do not substitute other letters.

Same treatment down each column, so English and Nepali pair up:
- Column 1, stacked: the first initial top-left, a small italic "&" in the middle, the second
  initial bottom-right, set diagonally like the "D&M" cone, in a thin high-contrast serif drawn as
  a fine line, with a delicate hand-drawn olive/jasmine sprig curving beside it. Antique gold
  (#A5823A).
- Column 2, signature: a wavy, flowing monoline handwritten script, like a light pen signature, the
  letters bouncing gently on the baseline, a long wavy swash running out from the last letter and
  curling back under the monogram. Deep leaf green (#3D5230).
- Column 3, one line: both initials and the "&" drawn as ONE continuous wavy line that loops from
  the first letter through the ampersand into the second without lifting the pen, finishing in a
  tiny heart-shaped loop. Rani pink (#E0218A).

Every stroke the same thin weight, smooth, crisp, playful but elegant. One colour per tile. Flat,
no fills, no gradients, no shadows, no extra words, no mock-ups. Square 1:1, high resolution.
```

Follow-ups:
- More fun: "make the strokes wavier and more bouncy, like the letters are swaying".
- Pick one: "redo only the column 2, top row tile, larger, on plain white", then vectorise it at
  vectorizer.ai. Monoline strokes like these vectorise very cleanly.
- If आ / अ come out wrong, ask for the bottom row blank and set the Nepali in Canva (Kalam is a
  monoline Devanagari that matches column 2), or ask me to draw it as an SVG.
